# 🪙 Wallet CLI — Мультивалютный Крипто-Кошелек на Go

[![Go Version](https://shields.io)](https://golang.org)

Интерактивное консольное приложение (CLI) для управления мультивалютными активами. Проект разработан в рамках изучения продвинутых концепций языка Go (Golang), включая асинхронность, интерфейсы, каналы и модульное тестирование.

---

## 🔥 Ключевые фичи проекта

- **📦 Модульная архитектура (SoC):** Логика полностью разделена на независимые пакеты (`wallet`, `notifier`, `main`).
- **🔀 Многопоточность и Горутины:** Реализован асинхронный фоновый аудитор баланса (`StartBackgroundAuditor`), работающий в параллельном потоке.
- **🧪 Безопасный обмен данными:** Взаимодействие между фоновыми потоками и главным меню построено на неблокирующих каналах (`chan string`) через конструкцию `select`.
- **🔌 Архитектура на интерфейсах:** Модуль уведомлений спроектирован через паттерн "Универсальная Розетка" (`Notifier`), что позволяет на лету менять способ отправки (Telegram/Email), не меняя ядро кошелька.
- **💰 Мультивалютность и Хэш-таблицы:** Балансы хранятся в структурах `map[string]float64` со скоростью поиска **O(1)** и динамической подстановкой UX-символов (\$, €, ₽).
- **💾 Постоянное хранение (Persistence):** Автоматическая сериализация данных в JSON-файл при любых изменениях баланса.
- **🛡️ Валидация и обработка ошибок:** Реализована строгая проверка ввода (защита от фейковых валют) и явная обработка кастомных ошибок (`ErrInsufficientFunds`, `ErrInvalidAmount`).
- **✅ Модульные Unit-тесты:** Ядро кошелька покрыто автоматическими тестами с использованием стандартного пакета `testing`.


## 🚀 Как запустить проект локально

### 1. Клонирование и запуск приложения
```bash
# Запуск интерактивного меню кошелька
go run main.go
```

### 2. Запуск автоматических тестов
```bash
# Прогон тестов для всех пакетов с подробным выводом
go test ./... -v
```
